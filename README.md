# OOP INVENTORY SYSTEM 

This project implements an inventory management system in C++ using Object-Oriented Programming principles.

The application models items and weapons through class inheritance and manages them inside a custom inventory structure.

## Concepts Used
- Object-Oriented Programming (OOP)
- Classes and Inheritance
- Encapsulation
- Operator Overloading
- Dynamic Memory Management

## Project Structure
- Item (base class)
- Weapon (derived class)
- Inventar (inventory container class)
- main.cpp (program entry point)
